Shape Check

Enter a resident's body sliders from Edit Shape and see how their proportions compare with a real person, with exact slider changes to paste into IM.

1 · The avatar

Height is optional. Edit Shape shows it at the top of the panel; it's used to catch mistyped sliders.

2 · Body sliders

Firestorm: Advanced menu (Ctrl+Alt+D to show it) › Character › Character Tests › Appearance to XML. The file lands in the viewer's logs folder. Reading it fills in the sliders below.

How it works: the sliders are run through the same skeleton maths the Second Life viewer uses (from Linden Lab's published viewer source), so lengths are real bone lengths. Proportion sliders move the skeleton itself and behave the same on every mesh body. Targets come from adult anthropometric averages; head size is an estimate calibrated on a LeLutka EvoX head, so treat it as rough on other heads. Heights are on Firestorm's scale, which matches measurements against prims.
